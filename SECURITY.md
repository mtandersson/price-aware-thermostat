# Security policy

This project is an experimental Home Assistant integration that can switch
mains-powered heating equipment. Both software vulnerabilities and unsafe
behaviour (for example a failure mode that leaves a heater on) are in scope.

## Reporting

Please report privately through GitHub's **Security → Report a vulnerability**
form on this repository rather than opening a public issue. Include the
integration version, Home Assistant version and steps to reproduce.

This is a personal project maintained on a best-effort basis; there is no
guaranteed response time.

## Supported versions

Only the latest commit on `main` is supported. No release has been approved for
unattended heating or frost protection; see the limitations in the README.
